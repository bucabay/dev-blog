# dev-blog

My personal dev blog. Static site built with [Astro](https://astro.build) on the
[Cactus theme](https://github.com/chrismwilliams/astro-theme-cactus) by Chris Williams.

## Commands

```bash
pnpm install
pnpm dev        # dev server on http://localhost:4321
pnpm build      # static build into dist/ + Pagefind search index
pnpm preview    # serve the built output
pnpm check      # astro check + biome
pnpm lint       # biome, applying fixes
pnpm format     # prettier
```

Search is generated by Pagefind as a postbuild step, so it only works against a built site
(`pnpm build && pnpm preview`), not in `pnpm dev`.

## Writing

| Type | Location         | URL              |
| ---- | ---------------- | ---------------- |
| Post | `content/posts/` | `/posts/<slug>/` |
| Note | `content/notes/` | `/notes/<slug>/` |
| Tag  | `content/tags/`  | `/tags/<tag>/`   |

A post is `content/posts/my-slug.md`, or `content/posts/my-slug/index.md` when it needs
co-located images. Frontmatter is validated by Zod in `src/content.config.ts` — invalid
frontmatter fails the build.

```yaml
---
title: "Under 60 characters" # required
description: "Used in listings, meta tags, and the OG image." # required
publishDate: "26 Jul 2026" # required
updatedDate: "1 Aug 2026" # optional
tags: ["astro", "typescript"] # optional
draft: true # optional, excluded from production builds
pinned: true # optional, max 3 on the homepage
coverImage: { src: "./cover.png", alt: "..." } # optional
---
```

Notes need `publishDate` as a full ISO 8601 timestamp with an offset (`2026-07-26T09:15:00Z`).

`content/posts/markdown-elements/` ships as a draft and renders every supported Markdown
element — useful for eyeballing styles after a dependency bump.

## Configuration

- `src/site.config.ts` — title, author, description, nav links, code themes
- `src/components/SocialList.astro` — social links
- `astro.config.ts` — integrations, manifest, Markdown pipeline
- `public/icon.svg` — favicon and app-icon source

**Before deploying:** set `url` in `src/site.config.ts` to the real domain. It drives the
sitemap, RSS feeds, canonical URLs, and OG image paths. Currently
`https://blog.fijiwebdesign.com/`.

Optional webmentions: copy `.example.env` to `.env` and fill in the
[webmention.io](https://webmention.io) values.

## Deploying

Any static host works — the build output is plain files in `dist/`.

```bash
pnpm build
```
