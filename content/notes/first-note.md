Half of what I learn in a week doesn't deserve 800 words. A compiler flag, a `git` incantation, a default that bit me, a package that turned out to be better than the popular one.

Those go here. One idea, a few sentences, no structure. They still show up in search and in the notes RSS feed, which is all I need from them.

Markdown content can't call the `withBase()` helper, so internal links written in a post should be relative (`../other-post/`) rather than absolute — absolute paths skip the site's base prefix and 404 on GitHub Pages.
